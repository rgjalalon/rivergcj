# Wai story film: footage slots

Put live-action clips in this folder using these exact filenames. On the next render, each clip replaces its animatic automatically. The same slow push, handheld drift and warm-dark grade are applied, so the whole film matches. Clips are cropped to fill a 1080×1040 letterboxed picture, so frame subjects with room around them.

Shoot everything with a shallow depth of field (f/1.4–2.8), practical light sources, and underexposure of about ⅓ stop. The grade adds the warmth.
